# 🌍 AI Translator Web App

A simple, fast, and interactive AI-powered translator built with Python and Streamlit. This app takes input text in one language and translates it into another using state-of-the-art language models.

## 🚀 Features

- 🧠 Supports multi-language translation using pretrained transformers
- 📱 Clean and responsive UI powered by Streamlit
- 🔤 Auto-detects source language (optional)
- ⚡ Fast and easy deployment
